# DataStructures

This work started with a reddit discussion (I know) about avoiding recursion. 
I pointed out that (IIRC) I could write an AVL Tree without recursion (I had done so some 25-30 years ago) by adding in a Parent to the tree node.

This reminded me of the old (and lost) C++ work I did with data structures (before stl IIRC) and I decided what the heck lets see if I can recreate some of them just for the heck of it. Maybe later on I can add in some algorithms.

I have no idea where this will take me or how far I will get with this. Maybe I'll just stop at ACL Trees maybe not.
